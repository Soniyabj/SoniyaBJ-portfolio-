PROJECT DEEP DIVE · 01

PreVisX: from “why won’t it run?” to a clearer next step

Explore repository
THE PROBLEM

When a project fails to start, it can be unclear whether the cause is a missing runtime, dependencies, environment configuration, or build setup.

THE APPROACH

PreVisX detects supported project types and checks relevant runtimes, dependencies, environment-file presence, configuration, ports, and recognizable build commands.

A DESIGN CHOICE

Keep checks local to the VS Code extension and require explicit approval for each supported Safe Fix. The extension does not upload project files or environment values.

EVIDENCE IN THE REPO

The repository documents a test suite covering detection, readiness checks, diagnoses, Safe Fix validation, malformed manifests, and webview hardening.

Read development & testing notes

Walk through it locally

  1. Open a supported project folder in VS Code.
  2. Choose the PreVisX icon in the Activity Bar.
  3. Review the detected project, readiness checks, diagnoses, and score.
  4. Run a full check; inspect any proposed Safe Fix and approve only if you want it applied.
