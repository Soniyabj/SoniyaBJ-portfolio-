# Soniya B J — Portfolio

Personal portfolio website highlighting my education, experience, projects, technical skills, certifications, and community contributions.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The site uses plain HTML, CSS, and JavaScript.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive layout and visual styling
- `script.js` — interactive navigation and typed introduction
- `photo.png` — profile photo
- `resume.pdf` — downloadable resume

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the publishing source, then save. GitHub Pages will provide the published website URL after deployment.
